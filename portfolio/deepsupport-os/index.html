工单场景 · 员工无法登录 Outlook

基于仓库支持的查询、排障和审批流程。

  1. 核对账号与工单查询账号状态和已有工单，避免重复创建。
  2. 按 SOP 排障根据查询结果调用相应的 Skill，确定下一步。
  3. 提交写操作审批如果需要重置密码，等人工批准后再执行。

把 IT 工单接进 Agent

为 Microsoft 365 企业 IT 支持场景搭建 Agent，把工单、邮件和知识库接进同一工作流。

任务编排与写操作审批

收到 Outlook、Teams 等问题后，Agent 先查账号和工单，再调用对应的 SOP Skill 排障。LangGraph 负责任务编排，Subagents 分担检索等子任务。

创建、升级或关闭工单，以及重置密码等写操作，都需要先通过人工审批。

本地运行

在仓库根目录复制 .env.example，在 .env 中按示例配置模型密钥，然后启动 Docker 服务。

cp .env.example .env
docker compose up --build -d

打开本机的 http://127.0.0.1:5173。可以用仓库的模拟数据走一遍排障流程，观察写操作如何进入人工审批。
