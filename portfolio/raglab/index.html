Hybrid RAG · 引用与拒答

RAGLab

源码与运行说明 ↗

做了什么

做了一套面向中文企业公开报告的问答工具，便于从 PDF 中查证信息。

怎么做

用 Docling 从 PDF 提取文本和表格。在 Qdrant 并行做语义和关键词检索，再对候选证据重排。

生成环节根据检索到的证据作答，并附上来源。超出语料范围的问题用于检查拒答行为。

结果

回答可以回查原文引用，证据不足时会拒答。检索质量可以在评测看板里检查。

如何体验

  1. 按仓库的快速开始配置模型与本地环境，启动 Qdrant。
  2. 准备公开 PDF，运行 scripts/ingest_demo_subset.py 入库。
  3. 启动前后端，打开本机的 http://localhost:5173，用示例问题检查回答、引用页码和拒答。
