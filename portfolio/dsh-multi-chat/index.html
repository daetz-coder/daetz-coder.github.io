DeepSeek Harness · 开源插件

dsh-multi-chat

查看 npm 包 ↗

做了什么

给 DeepSeek Harness 做了多窗口插件，用来同时查看多个 Agent 会话。

怎么做

用 TypeScript、React 和 Cordis 将多窗口注册为 DeepSeek Harness 的一个内置视图。窗口嵌入其他实例时会跳过自身端口，避免递归嵌套。

通过带认证的局域网网关接入手机或平板。

结果

桌面可并排查看多个会话，手机和平板可接入同一网关。插件已发布到 npm。

如何体验

如果已安装 DeepSeek Harness，可在 Web 配置中安装插件并启动多实例。

dsh plugin --profile web add dsh-multi-chat
npx dsh-multi-chat start --ports 3080,3081,3082

启动或重启实例后，在侧栏底部打开 Multi-window。桌面配置和局域网接入见仓库文档。
