简介

从 网络空间安全 与 机器学习 起步，一路走到 AI Agent 系统工程。关注 Agent Harness 编排、LangGraph 多智能体、HITL 人工闭环、混合检索与带引用生成，以及 LLM-as-Judge 的自动化评估。

持续打磨「可运行、可验证、可运营」的 AI 产品：一个组件 dsh-multi-chat 已发布 npm，并被 DeepSeek Harness 社区生态列表收录；其余项目覆盖企业支持、知识库、评估平台与移动协作。

研究兴趣：网络入侵检测（NIDS）、自动调制识别（AMC）、小样本学习（FSL）、SLAM 建图与多波束声呐数据处理。
