Extract transparent PNGs

Use the generated MP4 and crop layout from the same batch. The JSON records the grid, key color and foot baseline. The extractor maps the saved cells to the decoded video dimensions.

Run the sample

From the repository root, run the extractor with Python 3.10+, Pillow and FFmpeg installed.

python scripts/extract_frames.py \
  --video assets/video-inputs/blue-units-3x2-wan-prime-480p.mp4 \
  --layout examples/tiny-swords/wan-layout.json \
  --fps 10 --despill-magenta --out work/tiny-swords/frames

The --despill-magenta option removes compressed magenta spill near the transparent edge. At 10 fps, this five-second sample writes 50 candidate frames per cell and a manifest with crop bounds, foot anchors and edge-contact flags.
