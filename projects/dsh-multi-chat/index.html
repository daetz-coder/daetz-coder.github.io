作品介绍

为 DeepSeek Harness 而生的多窗口墙插件：一个屏幕并排监控多个 Agent 实例，通过认证网关在任何设备上续看会话，已被社区生态列表收录。

核心特性

多窗口墙

N 个 Agent 会话并排实时监控，一眼掌握全局状态。

认证局域网网关

设备扫码/口令认证接入，手机平板随时随地查看。

一行安装 / 一行卸载

npx dsh-multi-chat install 即装即用，零配置。

npm 发布

TypeScript + React + Cordis 构建，社区生态收录。
