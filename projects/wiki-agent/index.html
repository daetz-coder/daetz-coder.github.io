项目概览

个人知识库的轻量解法：把笔记、文档丢进去，用对话完成录入与召回，LangGraph 串联检索与生成。

实现要点

对话即录入
聊天式添加知识，无需维护复杂结构。
搜索即召回
自然语言提问直达相关内容。
LangGraph 编排
检索、生成、溯源走图式工作流。
Web 前端
Vue3 + FastAPI，开箱即用。
