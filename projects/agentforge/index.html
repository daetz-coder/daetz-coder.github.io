项目概览

无人值守场景的守护进程：检测 Cursor 用量上限或登录失效后，自动换号重登并让原会话继续执行。

实现要点

用量检测
监控对话额度与登录状态，达到阈值自动触发。
自动换号
切换可用账户，绕过用量墙。
同会话续跑
重登后注入原上下文，任务不中断。
桌面面板
Flutter UI 可视化运行状态与账户池。
