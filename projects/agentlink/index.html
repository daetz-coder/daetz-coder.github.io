项目概览

把 Claude Code 从桌面挪进口袋：主机台桥接会话，手机端审批工具调用、回答提问，同一会话无缝续跑。

实现要点

手机审批
工具调用与高风险操作推送到手机确认。
问答接力
会话中随时插入问题，手机作答后回传主线程。
同会话继续
WebSocket 双向桥接，会话上下文不丢失。
Flutter 双端
Windows 主机台 + Android App，一套体验。
