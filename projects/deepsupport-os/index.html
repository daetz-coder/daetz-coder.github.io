作品介绍

把企业级 IT 支持改造成可运营的 Agent 系统：以任务规划为主线，Skill/Subagent 分工执行，人工审批闭环兜底，评测体系保证质量可度量。

核心特性

M365 Help Desk 集成

面向微软 365 生态，把工单、邮件、知识库接入同一 Agent 工作流。

Skills / Subagents 分工

复杂任务拆解为可复用技能与子代理，LangGraph 编排执行。

HITL 人工闭环

关键操作需人工审批，事件驱动回传，兼顾效率与安全。

自动化评测

内置评测链路，验证任务完成度与回答质量。

界面 / 运行示意

线框示意，展示关键交互与数据形态；完整体验请运行仓库。
