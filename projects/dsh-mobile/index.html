项目概览

DeepSeek Harness 的移动伴侣：扫码即可配对桌面实例，接收任务状态通知，甚至可以远程控制会话。

实现要点

扫码配对
扫描桌面二维码一键关联，无需手动配置。
状态通知
任务完成、等待审批等状态实时推送手机。
远程控制
在手机上继续与管理桌面会话。
Capacitor Android
官方 DSH Web UI 的轻量容器封装。
