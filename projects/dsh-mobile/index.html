项目概览

DeepSeek Harness 的移动伴侣：扫码即可配对桌面实例，接收任务状态通知，甚至可以远程控制会话。

实现要点

扫码配对
扫描桌面二维码一键关联，无需手动配置。
状态通知
任务完成、等待审批等状态实时推送手机。
远程控制
在手机上继续与管理桌面会话。
Capacitor Android
官方 DSH Web UI 的轻量容器封装。

相关项目

  • dsh-multi-chat

安装与配对

  1. 按项目文档为桌面 DeepSeek Harness 安装 dsh-pocket 和 dsh-web-mobile，再启动 dsh web。
  2. 从 Releases 下载并安装 Android APK。
  3. 在桌面打开 Phone access，扫描二维码并输入配对 PIN。
