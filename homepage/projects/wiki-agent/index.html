作品介绍

个人知识库的轻量解法：把笔记、文档丢进去，用对话完成录入与召回，LangGraph 串联检索与生成。

核心特性

对话即录入

聊天式添加知识，无需维护复杂结构。

搜索即召回

自然语言提问直达相关内容。

LangGraph 编排

检索、生成、溯源走图式工作流。

Web 前端

Vue3 + FastAPI，开箱即用。

界面 / 运行示意

线框示意，展示关键交互与数据形态；完整体验请运行仓库。
